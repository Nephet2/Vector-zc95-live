How the responses work
Follow Channel 1: Channels 2, 3 and 4 can copy Channel 1 pulse repetition and width independently. Grey controls retain their saved values for when Follow is unticked. Power stays independent. If Channel 1 is inactive, its displayed idle texture values are copied.
Reading feedback: Green bars show configured ranges; gold markers show calculated commands, not measured output. In Scale mode the device applies the physical dial multiplier. Vector volume is a preset; the Power envelope dropdown remains authoritative afterward. At ratio 20, rolling speed spans 95-100% before rest, ramp and crossover.
Fixed uses the maximum value. Position follows 0–100% script position. Speed follows motion speed up to the selected reference (100%/s means one full script range per second). Inverse speed reverses that response. Blend combines position and speed using Speed mix; Inverse position + speed uses reversed position. Vector-like texture selects these blends with 500 ms texture damping. Speed comes from interval timing or command-arrival changes and decays after motion stops.
With rest reduction enabled, stopping motion applies the Rest level. On return to motion, Return ramp eases toward the normal response. Rest reduction scales modulation above the minimum. Power minimum is a running background floor, including outside the crossover region. Neutral, stale input and disabled channels command zero. Independent response damping slows texture changes without changing crossover position. This is envelope attack, not pulse-edge rise-time control.
Every channel has its own curve, source, direction, speed reference and smoothing. Curves multiply modulation above background; they do not divide a fixed total between channels. Pulse width denotes equal positive and negative phases. Channel numbers do not prescribe electrode positions or electrical phase relationships.
WebSocket/TCP input holds its last position while its connection stays healthy, even when MFP sends only changed values. UDP retains the interval-plus-two-second expiry. Lost links pause at zero and reconnect automatically while Run is requested. Stop and Hard Neutral cancel automatic resumption. Bluetooth output is explicitly armed and continuous, using the full configured power range. The browser watchdog is not a device-side watchdog. Leaving Demo clears cached live input. Settings are independent of the ReStim Vector app.
